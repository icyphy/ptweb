Ptolemy II 5.0.1 Notes for Mac OS X

Mac OS X Java 1.4 Instructions

Ptolemy II 5.0.1 requires Java 1.4 because it uses the java.net.URI class which is not present in Java 1.3.
Mac OS X 10.2 is required to run Java 1.4. In May, 2004 http://developer.apple.com/java/faq/index.html#gen_1 said:

Q: What version of Java is included on Mac OS X?

A: Mac OS X Panther initially shipped with installations of J2SE 1.3.1 and 1.4.1. Java 1.4.2 is now available for Mac OS X Panther v10.3.1, based on Sun's J2SE 1.4.2_03 SDK. This release features LiveConnect support with Safari, a new JFileChooser, integration with system proxy settings, and overall performance improvements. Please note that 1.4.2 completely replaces the current Java 1.4.1 implementation on Panther systems, and is not removableonce installed.

A developer preview of Java 1.4.2 Update 1 is also available to All ADC members via the ADC Member Site. Like the 1.4.2 release, the DP is not removable and will replace your current 1.4.x installation. Please limit installation of the previews to non-critical systems.

Mac OS X Jaguar initially shipped with J2SE 1.3.1 only. Java 1.4.1 Update 1, based on the J2SE 1.4.1_01 SDK, is available to Jaguar users through Software Update.

Mac OS X Web Start Problems

Under Mac OS 10.2 with Java 1.4, the Web Start binary downloads and starts up, but there might be a delay while the rest of the modules are pulled over the network.
