Ptolemy II 0.3 Download

This release consists of infrastructure for software developers who want to use Ptolemy to develop models of their own.
Note:
This is not the most recent version of Ptolemy II. The most recent version can be found at http://ptolemy.eecs.berkeley.edu/ptolemyII/ptIIlatest/.

There are a number of caveats with that go along with this snapshot.

  • Some of the files in this release have not been design reviewed, code reviewed, or thorough tested. Classes that have undergone design review are marked "yellow" in the source file. Classes that have undergone both design and code review are marked "green" in the source file.
  • The code in release is changing in our own development copy, and some of the changes are not backward compatible. You should not rely on the interface of any class that is rated at less than "green." In rare circumstances we may also modify the interface of green classes before the 1.0 release.
  • The primary difference between this release and the Ptolemy II 0.2 release is that this release includes domains, actors and documentation including a tutorial on writing applets.
    Ptolemy II 0.3 requires JDK1.2.
