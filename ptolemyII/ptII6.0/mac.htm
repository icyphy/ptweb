Ptolemy II 6.0.1 Notes for Mac OS X

We are not including Macintosh installers, you will need to rebuild download Ptolemy II sources and then follow the command line build instructions.

Note:
Ptolemy II 6.0.2 will not compile with Java 1.6, you must use Java 1.4 or 1.5, see 07-Apr-2008 Re: Error installing Ptolemy on ubuntu.

Macintosh Specific Notes

  • Make sure you have Xcode Tools installed, this has the gcc, make environment and other tools necessary to do development on the Mac. Xcode is available on the Macintosh install disk that comes with the machine and is not installed by default. You can also download Xcode, but it is 924Mb!
  • Upgrade the Java on the Mac from Apple to the latest release. Sun Java doesn't work on the Mac, Apple releases its own JVM and javac from time to time on http://developer.apple.com
  • See also the Ptolemy II 5.0 Mac Instructions
