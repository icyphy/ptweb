Ptplot on the Zaurus

Ptplot 1.0 and Ptplot 2.0 can run on the Sharp Zaurus! The basic idea is to recompile Ptplot using javac -target 1.1 and then run using evm
  1. Download http://ptolemy.eecs.berkeley.edu/java/ptolemy.plot2.0/ptolemy/plot/ptolemy.plot2.0.tar.gz to a Windows or Unix box
  2. Untar, set $PTII and configure: 
    cd ~/src
gtar -zxf /tmp/ptolemy.plot2.0.tar.gz
cd ptolemy.plot2.0
setenv PTII `pwd`
./configure
  3. Edit $PTII/mk/ptII.mk and add -target 1.1 to JFLAGS 
    JFLAGS = 	-g  -target 1.1
    Note that I had to remove -depend from the above line
  4. Run 
    make clean
make
make install
  5. This will produce ptolemy.plot2.0/ptolemy/plot/ptolemy.plot.jar, which
