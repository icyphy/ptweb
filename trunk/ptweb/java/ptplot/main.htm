Ptplot

Ptplot 5.1p1 is a 2D data plotter and histogram tool implemented in Java. Ptplot can be used as a standalone applet or application, or it can be embedded in your own applet or application.

April 26, 2002: Ptplot 5.2 is available as part of Ptolemy II 2.0-beta.
There are not that many changes between Ptplot 5.1p1 and 5.2.
We hope to have a standalone Ptplot release out eventually.

Ptplot a part of Ptolemy II, but Ptplot is also available as a separate download.

We've made a small standalone example available that uses Ptplot3.1.

ptolemy-plot-servlet.tar.gz is a gzipped tar file that contains sample code to use Ptplot as a servlet. The code was written by Alberto Gobbi, and has _not_ been tested by the Ptplot pteam at UC Berkeley.
