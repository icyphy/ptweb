Viptos 1.0-beta - Visual interface between Ptolemy and TinyOS

Viptos is an interface between TinyOS and Ptolemy II

Note: As of 2/06, Windows users must use gcc-3.2 to to run TinyOS models inside Ptolemy. The reason is that that Java Native Interface (JNI) is broken in newer versions of Cygwin. Windows users must install Cygwin from roughly August, 2003, such as Ptolemy II 3.0 Cygwin Devel

Despite the bug above, Windows users and other users can generate code by changing the PtinyOSDirector target from ptII to pc or some other tinyos target like mica or mica install. See $PTII/ptolemy/configs/viptos/help.htm for details. Only running a simulation within ptII involves JNI.

This release is called Viptos 1.0-beta, it is the second release of Viptos, which is based on Ptolemy II 6.0-devel.
The first release was named Viptos-5.1-alpha because it was released on the Ptolemy 5.1-alpha sources.
