Viptos - Visual interface between Ptolemy and TinyOS

Screenshots

This page shows screenshots of Surge. Surge is an example Viptos model that demonstrates use of the TinyOS 1.x Surge multihop routing protocol. Each node runs the TinyOS 1.x Surge application, which takes light level readings and forwards them to the base station.

Also see:

  • SenseToLeds - A simple light sensing example.
  • SendAndReceiveCnt - A sender and receiver example.
