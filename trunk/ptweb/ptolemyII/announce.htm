What's in Ptolemy II?

Ptolemy II 0.1

Ptolemy II 0.1alpha was shipped on November 26, 1998.

Ptolemy II 0.1alpha included:

  • A developer's release, consisting of only Java packages (kernel, actor, data, graph, plot, math). Ptolemy II 0.1 did not include the domains, a GUI, Tycho or Tcl Blend
  • Ptolemy II 0.1 included the Ptolemy II Design document

    • Ptolemy II 0.2

    Ptolemy II 0.2devel was shipped on February 25, 1999.

    Ptolemy II 0.2devel includes:

  • Everything we shipped in Ptolemy II 0.1 above
  • Initial implementations of several domains
  • The demonstrations we showed at the Ptolemy Miniconference

    • Ptolemy II 0.3

    Ptolemy II 0.3 was released on August 2, 1999

    Ptolemy II 0.3 includes:

  • The following domains:
  • Communicating Sequential Processes (CSP) - Neil Smyth
  • Continuous Time (CT) - Jie Liu
  • Distributed Discrete Event (DDE) - John Davis II
  • Discrete Event (DE) - Lukito Muliadi, Edward A. Lee
  • Process Networks (PN) - Mudit Goel
  • Synchronous Data Flow (SDF) - Steve Neuendorffer
  • Domain-polymorphic actors
  • Infrastructure for constructing applets
  • Documentation for model and actor developers
