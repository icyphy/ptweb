    • Mac OS X Specific Notes

    The Ptolemy installer for Mac will install a version of Ptolemy that does not include serial port support, or Java Media Framework support. In addition, Mac OS X may not have gcc installed by default.
    To add serial port support, Java Media Framework support and/or gcc, see Setting up a Mac for use with Ptolemy.
