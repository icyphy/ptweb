Ptolemy II 0.4beta

The Ptolemy II distribution is also available on our webserver so that you can run the demonstrations
Note that the applet demonstrations work best with Windows, and that you will need to have the JDK plugin from on JavaSoft installed. If you do not have the plugin installed, you can still browse the distribution and look at the source code and documentation.

Ptolemy II 0.4beta is the second Ptolemy II release to include domains, actors, and applets of sufficient quality and architectural stability to use as models for development. The domain-polymorphic actor libraries, in the ptolemy.actor.lib and ptolemy.actor.gui packages are still small, but reasonably solid.

Ptolemy II 0.4beta supports an XML language called MoML for specifying component-based models. Chapter 2 of the Ptolemy II Design Document describes how to use MoML to create models.

The Ptolemy II design document that is shipped with Ptolemy II 0.4beta is incomplete, we plan on finishing it in time for the full Ptolemy II 0.4 release that is scheduled for 3-4 weeks after Ptolemy II 0.4 beta ships.

The Ptolemy II 0.4 release notes describe limitations in the release.

The Ptolemy II 0.4 applets require the JDK1.2 plug-in. If you have JDK1.2 installed on your machine, then the plug-in may already be installed. You may obtain the JDK1.2 plug-in from JavaSoft The plug-in is easiest to use from a Windows machine. If you don't have access to a Windows machine, you can run the applets by downloading Ptolemy II 0.4 and running make demo. For more information, see the Plug-In section of the Installation page.

When you visit a Ptolemy II applet, the first applet that is run will download ptsupport.jar, which is 671k. Each applet then will download smaller domain specific jar files of between 18k and 65k. If you have a slow network connection, or if there is congestion in the network or on our server, you may experience significant delays before the first applet runs.

Some of the applets use Diva, a visualization package. diva.jar file is roughly 814k.

We would be interested in any feedback you might have concerning these demos. You can send email to ptII@eecs.berkeley.edu.
