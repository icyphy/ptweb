Ptolemy II 0.4 Download

This release consists of infrastructure for software developers who want to use Ptolemy to develop models of their own.
See the release notes for information about limitations of this release.
Ptolemy II 0.4 requires JDK 1.2., and works best with JDK 1.2.2 It will compile and run with JDK1.3rc1, but we have not extensively tested it.

Download

  • Gzipped Tar file: ptII0.4beta.src.tar.gz (12.3 Mb).
    Note that this tar file requires GNU tar or WinZip. Solaris 2.5.1 tar will fail to untar this file with a checksum error because the pathnames are longer than 100 characters. If you do not have GNU tar, you can obtain source and selected binaries from ftp://ptolemy.eecs.berkeley.edu/pub/gnu. You can also try the zip version below
  • Zip file: ptII0.4beta.src.zip (15.0 Mb)
  • Experimental Windows Installer ptII04betasetup.exe (15.2Mb)
  • This installer works best with JDK1.2.2.
  • To install, you will likely need Administrator privileges on your machine.
  • After installation, the Ptolemy II menu choice will appear towards the top of your Start -> Programs menu.
  • The CLASSPATH and PATH variables are not set because of known bugs in Installshield Java v3.00
  • The PTII variable is not set by the installer You will need to set the CLASSPATH, PATH and PTII variables by hand, see ptII0.4beta/doc/install.htm

  • Draft of the Ptolemy 0.4 Design Document: PDF
    This paper is included in the tar, zip and installer files above.
    • The tar files include all the .class, .jar and javadoc html documentation, so you need not recompile to use Ptolemy II. This release was compiled with JDK1.2.2 under Solaris 2.5.1

    For further information about rebuilding Ptolemy II, see ptII0.4beta/doc/install.htm
