Ptolemy II 0.3

Ptolemy II 0.3 consists of Java applet demonstrations developed to illustrate key points of the various models of computation in Ptolemy II.

The 0.3 release also includes actors and infrastructure for model writers.

The Ptolemy II 0.3 applets require the JDK1.2 plugin. If you have JDK1.2 installed on your machine, then the plugin may already be installed. You may obtain the JDK1.2 plugin from JavaSoft The plugin is easiest to use from a Windows machine. If you don't have access to a Windows machine, you can run the applets by downloading Ptolemy II 0.3 and running make demo. For more information, see the Plugin section of the Installation page.

The first applet that is run will download ptsupport.jar, which is 478k. Each applet then will download smaller domain specific jar files of between 18k and 65k. If you have a slow network connection, or if there is congestion in the network or on our server, you may experience significant delays before the first applet runs.

Some of the applets use Diva, a visualization package. diva.jar file is roughly 550k.

A known problem is that some of the applets do not stop properly, and will not run a second time without reloading the java code (use Shift-Reload under Netscape Communicator or Control-Reload under Microsoft Internet Explorer). If you have other problems, you may want to review the Troubleshooting Guide.

We would be interested in any feedback you might have concerning these demos. You can send email to ptII@eecs.berkeley.edu.
