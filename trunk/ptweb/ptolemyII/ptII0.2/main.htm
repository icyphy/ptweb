Ptolemy II Demonstration Snapshot

Note that there is a more recent version of Ptolemy II is available for download.
Rather than using this older version of Ptolemy II, please use the more recent version.
At the Ptolemy Miniconference on February 19, 1999, we showed several Ptolemy II applet demonstrations. These demonstrations represent a snapshot of the state of our development tree and are not viewed by us as production quality code. Nevertheless, we are making them available on the web in order to solicit feedback and to illustrate the trajectory of the project. We expect to release production quality code in mid 1999.

The first applet that is run will download ptsupport.jar, which is 325k. Each applet then will download smaller domain specific jar files of between 20k and 85k. If you have a slow network connection, or if there is congestion in the network or on our server, you may experience significant delays before the first applet runs.

Some of the applets use Diva, a visualization package that requires the JDK1.2 plugin. If you have JDK1.2 installed on your machine, then the plugin may already be installed. You may obtain the JDK1.2 plugin from JavaSoft The applets that require JDK1.2 are clearly marked. The diva.jar file is roughly 550k.

A known problem is that some of the applets do not stop properly, and will not run a second time without reloading the java code (use Shift-Reload under Netscape Communicator or Control-Reload under Microsoft Internet Explorer).

We would be interested in any feedback you might have concerning these demos. You can send email to ptII@eecs.berkeley.edu.
