Ptolemy II 1.0 beta Limitations

The Ptolemy II 1.0 Release notes list limitations. The Vergil welcome window has a link to a similar list.

Below we list limitations found after the Ptolemy II 1.0 beta release.

Installer limitations

  • We have only tested the Installshield Installers under Windows 2000 and Windows 98. Unix users should install from the ptII1.0beta.src.tar.gz tar file and follow the Installation Instructions
  • In the full Windows installer, the Ptiny choice does not install exactly the same files as the Ptiny choice in the Ptiny Windows installer. The Ptiny choice in the full installer does not install a subset of the Java documentation.
  • During uninstall, message about intro.htm comes up because we install it twice. The solution is to use a conditional??

    • Runtime limitations

  • Security concern dialog comes up when we run any model that contains a Sinewave actor via an applet.
    The problem is that the model is, in fact, being loaded over the net. So the warning is correct. However, the _entire model_ is being loaded over the net into an applet, so the warning need not be displayed.
  • Running the Networked demo via an applet on the local file system results in an AccessControlException.
  • vergil foo hangs. No window comes up if foo does not exist.

    • Compilation limitations

  • The tutorials in doc/tutorial do not compile
    • If you find bugs, check the limitations page inside Vergil, then check this page, and then send email to ptolemy@eecs.berkeley.edu

    In your email, please be sure to list

  • What operating system you are operating under (Windows 2000 SR1? Solaris 7?)
  • What version of Java you are running. (Run java -version, or use our Java Version Applet )
  • Whether the problem occurs in
  • Vergil
  • The local version of the web pages
  • The PtolemyII 1.0 beta website version of the web pages
