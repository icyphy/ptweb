Ptolemy II 1.0 beta Downloads

Below are instructions on how to install Ptolemy II 1.0 beta.

There are two versions of Ptolemy II 1.0 beta

  • Ptolemy II 1.0ptiny beta - A small release that includes only what is necessary to build and run models in common domains ( CT, DE, FSM, PN and SDF). The Ptiny version is primarily for Windows 2000, and the download is roughly 6Mb in size.
  • Ptolemy II 1.0 beta - The full version, which includes what is in the Ptiny version and what is necessary to create your own actors. The full version also includes experimental domains. The full version is for Windows 2000 and various flavors of Unix and the download is roughly 20Mb in size.

    • 1. Install Java

    All versions of Ptolemy II 1.0 require JDK1.2 or later.
    JDK1.3 is preferred.
    The Ptolemy II 1.0 Windows installers require JDK1.3 One way to determine what version of Java (if any) is installed is to run our Java Version Applet , which uses the JDK1.3 plugin.

    Another way is to runcommand below to see if you have Java installed and it is the proper version: 

    java -version
    If the command cannot be found, or the version that is printed is less than 1.3, you should installing JRE 1.3 or JDK 1.3

    JRE is the Java Runtime Environment, which does not include the compiler javac

    JDK is the Java Development Kit, which does include javac.

    Ptolemy II 1.0ptiny does not require javac. However, if you plan on the full version of Ptolemy II (not yet released) and writing your own actors, then you will need the JDK to compile your actors.

    We can make the JRE available for download, but to get the JDK, you need to go to http://java.sun.com/j2se/1.3/

  • Windows: Download and install the JRE: j2re-1_3_0_01-win.exe (5.1Mb)
  • Other Platforms: Download and install the JRE or JDK: http://java.sun.com/j2se/1.3/

    • 2. Install Ptolemy II

    Below are the instructions to install the two different versions of Ptolemy.

    2a. Ptolemy II Ptiny

  • There are two ways to install Ptolemy II ptiny on Windows machines:
  • Run the installer as an applet by clicking here.
    Note that while the installer permission request window states that the installer is from InstallShield, Ptolemy II itself is from UC Berkeley.
    • or
  • Download a Windows executable, (6Mb), and execute it.
  • Other Platforms: download the gzipped jar file:
    (Note that we have not tested this yet.)
    1. Download ptII1_0ptinybetasetup.jar.gz (5.6Mb)
    2. Uncompress it with either Winzip or Cygwin
    3. Run 
      java -jar ptII1_0ptinybetasetup.jar

    • Bugs

    The Installshield Installer has a number of bugs:
  • The size of the install may be reported as 0kb.
  • The percent completed bars may not work.
  • You may see the word 'malformed' in the initial installer window.
  • Installing a bundled JRE does not work well so we don't use it.
  • Other installer bugs can be found in the Installshield Multi-platform Release Notes.
    • Other bugs not listed on the limitations page inside Vergil:
  • The tutorials in doc/tutorial do not compile
  • We have only tested the installation procedure under Windows 2000 and Windows 98.
  • The javasound actor documentation is not included in the release.
    • If you find bugs, check the limitations page inside Vergil, then check this page, and then send email to ptolemy@eecs.berkeley.edu
