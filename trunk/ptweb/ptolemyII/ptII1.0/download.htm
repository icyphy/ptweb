Ptolemy II 1.0 beta Downloads

There are two versions of Ptolemy II 1.0 beta:

  • Ptolemy II 1.0ptiny beta - A small release that includes only what is necessary to build and run models in common domains ( CT, DE, FSM, PN and SDF). The Ptiny version is primarily for Windows 2000, and the download is roughly 6Mb in size.
  • Ptolemy II 1.0 beta - The full version, which includes what is in the Ptiny version and what is necessary to create your own actors. The full version also includes experimental domains. The full version is for Windows 2000 and various flavors of Unix and the download is roughly 20Mb in size.

    • 1. Install Java, if necessary

    All versions of Ptolemy II 1.0 require Java 1.2 or later. Java 1.3 is preferred, and for some of the demos, required. The Ptolemy II 1.0 Windows installers require Java 1.3. To run Ptolemy II, the Java runtime environment (JRE) is sufficient. To run the applets in a browser, the Java plug-in is required. The JRE is bundled with the plug-in, so downloading the plug-in is sufficient. To extend Ptolemy II with your own Java code, the Java development kit (JDK) or an equivalent Java development environment is required. The JDK includes a Java compiler.

    One way to determine what version of Java (if any) is installed is to run our Java Version Applet , which uses the Java 1.3 plug-in. Another way is to run the command below to see whether you have Java installed, and whether it is the proper version: 

    java -version
    If the command cannot be found, or the version that is printed is less than 1.3, you should install the plug-in, JRE 1.3, or JDK 1.3

    Downloads:

  • Windows JRE: The Java runtime environment, JRE (no Java compiler): j2re-1_3_0_01-win.exe (5.1Mb)
  • Full JDK, or other Platforms: http://java.sun.com/j2se/1.3/

    • 2. Install Ptolemy II

    2a. Ptolemy II Ptiny

  • There are two ways to install Ptolemy II Ptiny on Windows machines:
  • Run the installer as an applet. This applet, from InstallShield, will install Ptolemy II, from Berkeley, on your machine.
    • or
  • Download a Windows executable, (6Mb), and execute it.

  • Other Platforms: download the gzipped jar file:
    (Note that we have not tested this yet. Please let us know whether it works or not by sending email to ptII@ptolemy.eecs.berkeley.edu.)
    1. Download ptII1_0ptinybetasetup.jar.gz (5.6Mb)
    2. Uncompress it with either Winzip or Cygwin
    3. Run on the command line: java -jar ptII1_0ptinybetasetup.jar

    • Bugs

    The Installshield Installer has a number of bugs:
  • The size of the install may be reported as 0kb.
  • The percent completed bars may not work.
  • You may see the word 'malformed' in the initial installer window.
  • Installing a bundled JRE does not work well so we don't use it.
  • Other installer bugs can be found in the Installshield Multi-platform Release Notes.
