Ptolemy II 2.0.1 Limitations

The Ptolemy II 2.0.1 Release notes list limitations. The Vergil welcome window has a link to a similar list.

Eventually, this page will list limitations found after the Ptolemy II 2.0.1 release.

If you find bugs, check the limitations page inside Vergil, then check this page, and then send email to ptolemy@eecs.berkeley.edu

In your email, please be sure to list

  • What operating system you are operating under (Windows 2000 SR1? Solaris 8?)
  • What version of Java you are running. (Run java -version, or use our Java Version Applet )
  • Whether the problem occurs in
  • Vergil
  • The local version of the web pages
  • The PtolemyII 2.0.1 website version of the web pages
  • The Web Start version
