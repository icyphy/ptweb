Ptolemy II 2.0.1 Limitations

The Ptolemy II 2.0.1 Release notes list limitations. The Vergil welcome window has a link to a similar list.

If you find bugs, check the limitations page inside Vergil, then check this page, and then send email to ptolemy@eecs.berkeley.edu

In your email, please be sure to list

  • What operating system you are operating under (Windows 2000 SR1? Solaris 8?)
  • What version of Java you are running. (Run java -version, or use our Java Version Applet )
  • Whether the problem occurs in
  • Vergil
  • The local version of the web pages
  • The PtolemyII 2.0.1 website version of the web pages
  • The Web Start version

    Dragging AudioReader into the canvas results in an error (8/26/02)

    If you drag the AudioReader actor into the canvas, you will get 
    ptolemy.kernel.util.IllegalActionException: Error evaluating expression
 "file://" + property("ptolemy.ptII.dir") + 
 "/ptolemy/actor/lib/javasound/test/voice.wav""
    in ..AudioReader2.sourceURL
 Because:
  Failed to evaluate sourceURL 
    '"file://C:\ptII/ptolemy/actor/lib/javasound/test/voice.wav"'
        in ..AudioReader2
 Because:
  C
 at ptolemy.data.expr.Variable.validate(Variable.java:1029)
...
    The reason the error occurs is because under Windows $PTII will likely have a backslash which causes problems when creating a URL. The fix is to add a new property called ptolemy.ptII.dirAsURL to $PTII/ptolemy/data/expr/UtilityFunction.java and modify $PTII/ptolemy/actor/lib/javasound/AudioReader.java to use it.
