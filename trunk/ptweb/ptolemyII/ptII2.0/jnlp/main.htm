Ptolemy II 2.0 Web Edition Download

This is a demonstration release of Ptolemy II. It is a preliminary version of the 2.0 release, and does not include source code. It uses an experimental web launching tool called WebStart that makes installation and updates particularly simple. You will get security warnings when performing this installation because we have not yet obtained a validated certificate. Those warnings will disappear soon. This release is being made available for use by the Mobies project participants. Other uses are not encouraged at this time.

Quick Start

Installation Details

Web Start is a product from Sun that is used to download the Ptolemy II 2.0 Web Edition.
  1. This web page attempts to detect whether Web Start is already installed. If the Quick Start list above contains
    Install Web Start from Sun (~5.3Mb)
    then download and install Web Start by following the Install Web Start from Sun (~5.3Mb) link.
    If the above step is not present, then Web Start is already installed and you can proceed with clicking on the
    Ptolemy II 2.0 Web Edition (~10Mb)
    link and continue with step 4 below.
  2. After installing Web Start, restart your browser and return to this page.
  3. Hopefully, the Web Start detection will work and the Install Web Start from Sun (~5.3Mb) step will not be present.
    Even if the Install Web Start step is present, try downloading the Ptolemy II 2.0 Web Edition (~10Mb), it could be that the Web Start detection has failed even though Web Start is properly installed.
  4. The download is roughly 10Mb, roughly half the size of the application download is consumed by the HTML documentation of the Ptolemy II Java classes.
  5. Note that the Ptolemy II Web Start applications may be signed with a certificate that is not registered with a certificate authority, so you may be prompted with a window stating that the certificate from Claudius Ptolemaus is unknown. You should hit the OK button to proceed with start up.
For more information about installation, see the Web Start Help page.
