Ptolemy II 2.0 Web Edition Download

This is a demonstration release of Ptolemy II. It is a preliminary version of the 2.0 release, and does not include source code. It uses an experimental web launching tool called Web Start that makes installation and updates particularly simple.
This release is being made available for use by the Mobies project participants. Other uses are not encouraged at this time.

Quick Start

Installation Details

Web Start is a product from Sun that is used to download the Ptolemy II 2.0 Web Edition.
  1. This web page attempts to detect whether Web Start is already installed. If the Quick Start list above contains
    Install Web Start from Sun (720KB - 8.6Mb)
    then download and install Web Start by following the Install Web Start from Sun (720Mb - 8.6Mb) link.

    If you already have the Java Runtime Environment version 1.2.2 (JRE 1.2.2) or higher installed, you only need the Java Web Start Update, which is 720Mb.

    If you do not have the Java Runtime Environment installed, or you are not sure, then you would need to downlod the Full Java Web Start package (5.7Mb), which inclues a JRE.
    If the above step is not present, then Web Start is already installed and you can proceed with clicking on the

    Ptolemy II 2.0 Web Edition (~11.1Mb)
    link and continue with step 4 below.
  2. After installing Web Start, restart your browser and return to this page.
  3. Hopefully, the Web Start detection will work and the Install Web Start from Sun (720KB - 8.6Mb) step will not be present.
    Even if the Install Web Start step is present, try downloading the Ptolemy II 2.0 Web Edition (~11.1Mb), it could be that the Web Start detection has failed even though Web Start is properly installed.
  4. The download is roughly 11.1Mb, roughly half the size of the application download is consumed by the HTML documentation of the Ptolemy II Java classes.
  5. After the download completes, you will be prompted with a window that states that the certificate from University of California Berkeley is valid. You should hit the Start button to proceed with start up.
  6. Read the Ptolemy II tutorial, available in PDF and HTML and experiment with constructing your own models.
For more information about installation, see the Web Start Help page.
