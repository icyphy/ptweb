Ptolemy II 2.0 JNLP Release

This is an internal interim runtime only release of Ptolemy II. The download does not include source files.

Quick Installation Instructions

Web Start is a product from Sun that uses the Web to download applications.
  1. This web page attempts to detect whether Java Web Start is already installed. If the box below contains 
     You need to Install Web Start from Sun before installing . . .
    Then download and install Java Web Start by following the Install Web Start from Sun link
  2. Restart your browser and return to this page.
  3. Hopefully, the Web Start detection will work and the You will need to install Web Start from Sun message will not be present.
    Even if the message is present, try downloading Vergil by clicking on the link
  4. Note that the Ptolemy II Web Start applications may be signed with a certificate that is not registered with a certificate authority, so you may be prompted with a window stating that the certificate from Claudius Ptolemaus is unknown. You should hit the OK button to proceed with the download.
  5. The download is roughly 10Mb, roughly half the size of the application download is consumed by the HTML documentation of the Ptolemy II Java classes.
For more information, see the Web Start Help page.
