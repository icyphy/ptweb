Ptolemy II 4.0.1 Web Edition Download

This download of Ptolemy II uses a web launching tool called Web Start that makes installation and updates particularly simple.

Quick Start

Installation Details

Below are more detailed instructions.

Web Start is a product from Sun that is used to download the Ptolemy II 4.0.1 Web Edition.

Java 1.5 problem

Under Java 1.5, this version of the Ptolemy II Web Edition might not start up, you might see a message about 
java.lang.NoClassDefFoundError: ptolemy/vergil/VergilApplication
The problem is that Java 1.5 handles lazy downloads differently than previous versions. The workaround is to install a more recent version of Ptolemy II Web Edition.
  1. This web page attempts to detect whether Web Start is already installed. If the Quick Start list above contains
    Install Web Start from Sun (720KB - 8.6Mb)
    then download and install Web Start by following the Install Web Start from Sun (720Mb - 8.6Mb) link.

    If you already have the Java Runtime Environment version 1.4 (JRE 1.4) or higher installed, you only need the Java Web Start Update, which is 720Mb.

    If you do not have the Java Runtime Environment installed, or you are not sure, then you would need to download the Full Java Web Start package (5.7Mb), which includes a JRE.
    If the above step is not present, then Web Start is already installed and you can proceed with clicking on the

    Ptolemy II 4.0.1 Web Edition (~29.8Mb)
    link and continue with step 4 below.
  2. After installing Web Start, restart your browser and return to this page.
  3. Hopefully, the Web Start detection will work and the Install Web Start from Sun (720KB - 8.6Mb) step will not be present.
    Even if the Install Web Start step is present, try downloading and/or opening the Ptolemy II 4.0.1 Web Edition (~29.8Mb), it could be that the Web Start detection has failed even though Web Start is properly installed.
    For example, under Opera 6.01 under Windows 2000, click on the Ptolemy II 4.0.1 Web Edition (~29.8Mb) link and select open. If Java Web Start has been installed, then it should start up automatically.
  4. The download is roughly 29.8Mb, roughly half the size of the application download is consumed by the HTML documentation of the Ptolemy II Java classes.
  5. After the download completes, you will be prompted with a window that states that the certificate from University of California Berkeley is valid. You should hit the Start button to proceed with start up.
