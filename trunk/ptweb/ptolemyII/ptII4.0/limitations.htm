Ptolemy II 4.0-beta Limitations

The Ptolemy II 4.0-alpha Release notes list limitations. The Vergil welcome window has a link to a similar list.

If you find bugs, check the limitations page inside Vergil, then check this page, and then send email to ptolemy@eecs.berkeley.edu

In your email, please be sure to list

  • What operating system you are operating under (Windows XP sp1? Solaris 8?)
  • What version of Java you are running. (Run java -version, or use our Java Version Applet )
  • Whether the problem occurs in
  • Vergil
  • The local version of the web pages
  • The PtolemyII 4.0-alpha website version of the web pages
  • The Web Start version

    • Places to go

  • Online Applet Demonstrations and Documentation
  • Ptolemy II Design Document

    • Contents

  • See the Ptolemy II 4.0-alpha Release notes for known limitations.
  • Ptolemy II 4.0-beta does not work very well at all under Mac OS X. See the Ptolemy II 4.0-beta Notes for Mac OS X page for details.
