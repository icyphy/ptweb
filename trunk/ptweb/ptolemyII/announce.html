What's in Ptolemy II?

Ptolemy II 0.1

Ptolemy II 0.1alpha was shipped on November 26, 1998.

Ptolemy II 0.1alpha includes:

  • A developer's release, consisting of only Java packages (kernel, actor, data, graph, plot, math). Ptolemy II 0.1 does not include the domains, a GUI, Tycho or Tcl Blend
  • Ptolemy II 0.1 includes the Ptolemy II Design document

    • Ptolemy II 0.2/h2> Ptolemy II 0.2devel was shipped on February 25, 1999.

    Ptolemy II 0.2devel includes:

  • Everything we shipped in Ptolemy II 0.1 above
  • Initial implementations of several domains
  • The demonstrations we showed at the Ptolemy Miniconference

    • Ptolemy II 1.0

    Ptolemy II 1.0 is to be shipped in late May, 1999.

    Ptolemy II 1.0, the first release full release of Ptolemy II, will include:

  • Everything we shipped in Ptolemy II 0.1 above.
  • The following domains are in the process of being written:
  • Communicating Sequential Processes (CSP) - Neil Smyth
  • Continuous Time (CT) - Jie Liu
  • Discrete Event (DE) - Lukito Muliadi
  • Process Networks (PN) - Mudit Goel
  • Star Charts (SC) - Xiaojun Liu
  • Synchronous Data Flow (SDF) - Steve Neuendorffer
  • We are not necessarily planning on shipping a gui block diagram editor with Ptolemy II 1.0
