Tycho 0.3 alpha

Tycho 0.3 alpha includes support for Itcl3.0/Tcl8.0/Tk8.0.

Unfortunately, Tycho 0.3 is not yet up to the Ptolemy Group's usual software standards, so we are not releasing Tycho 0.3 alpha to the general public.

However, if you want to download a copy of Tycho 0.3 alpha, send email to cxh@eecs.berkeley.edu and you will receive instructions on where to download it from.

Below is a list of known bugs:

  • The keyboard menu traversal system is badly broken. Tycho should be using the Tk 8 Menubar infrastructure.
  • The Windows menu gets confused if you have more than 10 windows open
  • Tycho occasionally exits when a window is closed. This happens rarely.
