ispell
ispell is used under windows for the Spelling checker. This version of Ispell requires Cygwin32 b20.1
  1. In a bash shell, run 
     mkdir -p /usr/local/bin /usr/local/lib/ispell
  2. Download the zipped ispell.exe Windows binary, unzip it and place it in /usr/local/bin
  3. Download the zipped ispell.dict, uncompress it and place it in /usr/local/lib/ispell
  4. Download the zipped ispell.words, uncompress it and place it in /usr/local/lib/ispell
  5. The ispell binary requires that your Path under NT have two directories in it:
  6. Be sure that the Cygwin bin directory that contains cygwin1.dll is in your path. Usually this will be something like D:\cygnus\cygwin-b20\H-i586-cygwin32\bin
  7. Add /usr/local/bin to your NT Path. Note that if your Cygwin installation is actually on the d: drive, then you would add D:\usr\local\bin to your Path.
    8. Under NT 4.0, to adjust your path, go to the Start menu, select Settings, then Control Panels, then System, then select the Environment tab

    pxgraph
    pxgraph is an extension to the Unix xgraph utility. pxgraph is not used by Tycho, but it is used by Ptolemy, so if you are running Ptolemy under NT, you will need pxgraph. A Java implementation of pxgraph can be found at http://ptolemy.eecs.berkeley.edu/java/ptplot.
