    Itcl

    To run Tycho0.2.1, you will need Itcl2.2. If you have installed Ptolemy0.7.1, note that it includes Itcl2.2. Itcl2.0, which was shipped with Ptolemy0.6 will not work with Tycho0.2.1.

    Itcl2.2 Downloads

    The following files are local copies of files from www.tcltk.com
  • Itcl Tutorial (gzipped PostScript tar, 820K compressed) (Original tar file from Lucent)
  • Itcl2.2 sources itcl2.2.tar.gz which includes Tcl7.5 and Tk4.1 (Original tar file from Lucent)
  • Itcl2.2 Windows binaries itcl22.exe (1.9Mb) (Original tar file from Lucent)
    • The following files were produced locally
  • Itcl2.2 prebuilt HPUX10.2.10 files (5.2Mb compressed)
  • Itcl2.2 prebuilt Solaris2.5.1 files (4.9Mb compressed)
  • Itcl2.2 prebuilt SunOS4.1.3 files (4.9Mb compressed)

    • Itcl2.2 Windows Installation instructions

    1. Download the Itcl2.2 Windows binary.
    2. Execute itcl22, which will start the installation procedure. It is best if you install Itcl2.2 in a directory that does not have spaces in the pathname.
    3. Download Tycho0.2.1 zipped file (1.89Mb). It is best if you install it in c:\tycho0.2.1
    4. See the Tycho under NT page for further instructions.

    Itcl2.2 Unix Installation instructions

    We provide binaries for HPUX10.2.10, Solaris2.5.1 and SunOS4.1.3.
    There are three different scenarios:
    1. If you are running an OS other than the three listed above, you will have to compile Itcl2.2 from source by downloading the Itcl source file and following the instructions.
    2. If you are running an OS that we provide binaries for then you can download the prebuilt binaries.
      The prebuilt Itcl2.2 Unix binaries have the pathname /users/ptolemy/tcltk hardcoded into them. If you download the binaries and place them at that location, then Itcl is more likely to work for you.
      1. Download the appropriate Unix Itcl2.2 binary to /tmp
      2. As root, make the following directory, and cd to it: 
        	mkdir -p /users/ptolemy/
	cd /users/ptolemy/
      3. Then untar the GNU gzipped files, for example for Solaris2: 
        	gunzip /tmp/itcl2.2.sol2.5.tar.gz | tar -xf -
        For hppa or sun4, use the appropriate file.
      4. Set your TYCHO variable, your path and start Tycho. Under csh, do: 
        	setenv TYCHO /users/ptolemy/tycho0.2.1
	set path = ($TYCHO/bin $path)
	tycho
    3. If you are running and OS that we provide binaries for but you cannot place the Itcl prebuilt binaries at /users/ptolemy/tcltk, then you can try using $TYCHO/bin/itkwish to start up Tycho. This C-shell script version of itkwish reads the ITCLDIR environment variable, sets some environment variables accordingly and then starts the real itkwish.
      1. Download the appropriate Unix Itcl2.2 binary to /tmp. Download the Tycho sources.
      2. Ungzip and untar the file where ever you feel like: 
        	cd /usr/local
	gunzip /tmp/itcl2.2.sol2.5.tar.gz | tar -xf -
	gunzip /tmp/tycho0.2.1.tar.gz | tar -xf -
      3. Set your ITCLDIR to the directory that includes the Itcl prebuilt distribution. Set the TYCHO variable, your path and start Tycho. Under csh, do: 
        	setenv ITCLDIR /usr/local/tcltk
	setenv TYCHO /usr/local/tycho0.2.1
	set path = ($TYCHO/bin $path)
	tycho
    See the Tycho under Unix page $TYCHO/doc/tyunix.html for further instructions.

    itkwish details

    If you are interested in using Itcl, but don't want to download Tycho, then note that the unix prebuilt binaries include
    tcltk/itcl/bin contains the following scripts:
    itkwish
    This file is a copy of $TYCHO/bin/itkwish.
    itclsh
    This file is a hard link to itkwish.
    ptarch
    This is a script that returns a value to identify the current architecture. For instance, under Solaris2.5.1, ptarch will return sol2.5. If the PTARCH variable is not set, then the itkwish script uses this value to set up the architecture dependent paths.
    To use the prebuild Itcl binaries without downloading Tycho:
    1. Download, ungzip and untar the appropriate file.
    2. Set your ITCLDIR variable to the tcltk directory.
    3. Set your path to include the scripts: 
      set path = ($ITCLDIR/itcl/bin $path
