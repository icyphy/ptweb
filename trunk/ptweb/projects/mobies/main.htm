MoBIES

This project is funded by the Defense Advanced Research Projects Agency (DARPA).

  • Principal Investigator: Edward A. Lee
  • Organization: University of California at Berkeley
  • Start date: March 2000
  • End date: December 2002

Overview

The Model Based Integration of Embedded Software (MoBIES) project is a 4 phase, 33 month, Defense Advanced Research Project Agency (DARPA) sponsored program to develop Process-Based Software Components for Networked Embedded Systems.

Embedded software is that which resides in devices that are not first-and-foremost computers. It is pervasive, appearing in vehicles, communications devices, aircraft, security systems, weapons systems, consumer electronics, toys, trains, printers, modems, copiers, thermostats, manufacturing systems, appliances, etc. Embedded systems is a rapidly growing market, estimated to be $1.6 billion/year by 2003 with a 15% annual growth rate (http://www.esofta.com/vdcsummary.pdf)

Objective

Our focus is on the design of process-oriented components and their runtime environment for networked embedded systems. The emphasis of this project is on the dynamics of the components, including the communication protocols that they use to interface with other components and the modeling of their state. The objective is to provide mechanisms for introspection, supporting both the ability of the run-time environment to safely dispatch tasks and the ability of components to adapt their interfaces using polymorphism. The focus is on real-time applications, which implies that models of time are a critical part of the abstractions that we will develop. The purpose of the mechanisms we develop is to improve robustness and safety while promoting component-based design.

Scope

Our plan is to build on top of Java infrastructure, particularly its networking support (initially at least, JINI and CORBA). We will coordinate with other contractors on the run-time environment, especially on thread scheduling with real-time capabilities. The main focus, however, will be on how process-oriented components are designed, how their interfaces are defined and reflected at run time, how their state is reflected at run time, and how this reflected information can be used to promote robustness, safety, and real-time performance.
