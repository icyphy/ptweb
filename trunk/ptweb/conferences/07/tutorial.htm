Ptolemy Tutorial

Monday, February 12, 2007 - Berkeley, California

We offered a Ptolemy Developer's Tutorial on Monday, February 12, 2007 in 540 A/B Cory on the UC Berkeley campus. This tutorial was for Java programmers who are interested in extending Ptolemy. 30 people attended the tutorial.

The agenda was:

  • 8:30 Overview of the day
  • 8:45 Building Ptolemy II (Christopher Brooks)
  • CVS access
  • configure
  • Coding Style
  • 9:45 Break
  • 10:15 Developing Actors (Yang Zhao, Eleftherios D. Matsikoudis)
  • Adding an actor to the tree
  • Testing
  • 12:00 Lunch (Provided)
  • 12:45 Developing Codegen Actors(Gang Zhou, Man-Kit Leung)
