Ptolemy Tutorial

Monday, February 12, 2007 - Berkeley, California

We will offer a Ptolemy Developer's Tutorial on Monday, February 12, 2007 in 540 A/B Cory on the UC Berkeley campus. This tutorial is for Java programmers who are interested in extending Ptolemy. It will be a hands on tutorial, please bring a laptop with the following installed:

  • Java JDK 5.0 This is also known as JDK 1.5.0 or Java SE 5.0
  • Ptolemy II 6.0 sources
  • Eclipse Eclipse is somewhat optional, though many of the Ptolemy developers use it.

    • We will have CDs with these packages on them available at the tutorial.

    Most UC Berkeley Ptolemy developers use Windows. If you have a Mac, we will do our best.

    The current draft agenda is:

  • Registration, Continental Breakfast, Laptop setup
  • Overview of the day
  • Building Ptolemy II (Christopher Brooks)
  • CVS access
  • configure
  • Coding Style
  • Developing Actors (Yang Zhao, Eleftherios D. Matsikoudis)
  • Adding an actor to the tree
  • Testing
  • Break
  • Developing Codegen Actors (Gang Zhou, Man-Kit Leung)
  • Lunch (Provided)
  • Choosing Domains (Edward Lee & Christopher Brooks)
  • Developing Domains (Edward Lee)
  • Break
  • Extending the User Interface (Edward Lee)
  • Reception
    • If there are other topics you would like to see covered, please let us know.

    Please note that the Ptolemy Miniconference is the following day, Tuesday, February 12, 2007.

    The Center for Hybrid and Embedded Software Systems (CHESS) will hold a meeting on Wednesday, February 14, 2007.

    The 2007 Berkeley EECS Annual Research Symposium (BEARS) will be on Thursday, February 15.

    Please register for the tutorial. Registration will close on February 2.
