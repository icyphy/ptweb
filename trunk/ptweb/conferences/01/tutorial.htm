Ptolemy II Tutorial

Friday afternoon, March 23, will be devoted to a tutorial on Ptolemy II, covering the following topics:

  • Using and extending the user interface
  • Overview of the actor libraries
  • Overview of the domains
  • How to write actors
  • How to write applets
The latter two topics require some background in Java programming.

We strongly recommend that you bring a laptop computer running Windows 98 or Windows 2000. This will enable you to follow the tutorial on your own machine, developing applications and code as you go.

You must register in advance to attend the tutorial, as space is limited.
