Abstract of Code Generation in Ptolemy II
Shuvra S. Bhattacharyya, University of Maryland at College Park
ssb@eng.umd.edu

Code generation in Ptolemy II uses two styles: deep and shallow. Deep code generation is the approach used by Jeff Tsay to read in Java classes, generate an AST and output Java code that has few depencies on the Ptolemy classes. Shallow code generation reads in a model and generates Java code for a composite actors that implements that model. The poster will compare and contrast these two styles.
