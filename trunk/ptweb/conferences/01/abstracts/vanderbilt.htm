A Ptolemy Implementation Of The Transcend System For Fault Detection And Isolation Of Dynamic Systems.

Eric-J Manders and Gautam Biswas
Vanderbilt University
manders@vuse.vanderbilt.edu

The Transcend method for fault detection and isolation (FDI) of dynamic systems combines a model based approach with qualitative residual analysis to effectively realize a qualitative parameter estimation approach to diagnosis. The approach couples a qualitative diagnosis engine with a signal-to-symbol transformation component that extracts symbolic feature values from continuously sampled data. In addition, Transcend is either in fault detection mode or in fault isolation mode. The symbolic feature values required in each mode are different and in a sophisticated implementation the set of symbols to be computed can be reconfigured while the system is running by using Ptolemy's ability to combine data flow components with finite state automata.
