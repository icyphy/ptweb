Papers on Semantics

Semantics of Ptolemy II

The following papers describe the background semantics underlying the core infrastructure of Ptolemy II.
  1. The Tagged Signal Model
  2. Timed Concurrent Systems using a Generalized Ultrametric formulation
  3. Timed Concurrent Systems using a CPO formulation
  4. Software Realization (see the Actor Package chapter)

  1. Continuous Time and Hybrid Systems
  2. Synchronous Reactive
  3. Timed Multitasking
  4. Multidimensional Synchronous Dataflow
  5. Discrete Time
  6. Discrete Events:
  7. Communicating Sequential Processes
  8. Process Networks
  9. Synchronous Dataflow
  10. Software Realizations
