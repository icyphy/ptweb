Guidelines for Searching the Ptolemy Project Paper Archive

The expressions for the search patterns are in the form of perl regular expressions.

Example keywords: blocking factor, codesign, convolution, courseware, dataflow, decimation, dynamic, equalization, Gabriel, graph, hardware, heterogeneous, hierarchical, interprocessor communication, looped schedules, memory, modeling, multidimensional, multiprocessor, network, partitioning, Ptolemy, process networks, scheduling, simulation, software, specification, static, symbolic, synchronization, synchronous, synthesis, token.

Help on the publication file formats

Help on the publication file formats

Adobe Acrobat PDF File Freely available viewers for the Macintosh, Windows, UNIX platforms can be obtained from the Adobe Acrobat home page.
Postscript file These files are compressed and formatted for Postscript printers or previewers.

To print one of these files, you must uncompress it and then send it to a Postscript printer. First download the file and then use the following command:

gzcat filename | lpr

If you have ghostview installed, you can preview the papers online using the command:

gzcat filename | ghostview -

HTML format A WWW browser such as Netscape will be able to display this format.
