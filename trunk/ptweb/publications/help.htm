Help with Search

The expressions for the search patterns are perl regular expressions.

Example keywords: blocking factor, codesign, convolution, courseware, dataflow, decimation, dynamic, equalization, Gabriel, graph, hardware, heterogeneous, hierarchical, interprocessor communication, looped schedules, memory, modeling, multidimensional, multiprocessor, network, partitioning, Ptolemy, process networks, scheduling, simulation, software, specification, static, symbolic, synchronization, synchronous, synthesis, token.

Help with File Formats

Adobe Acrobat PDF File can be read with the free acrobat reader.

Postscript files can be read with Ghostview.

HTML can be read with Netscape (for example).
