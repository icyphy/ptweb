Multiprocessor DSP Code Synthesis in Ptolemy

by Praveen Murthy

Memorandum UCB/ERL M66/93
EECS, University of California, Berkeley, CA, USA 94720
August 1993

ABSTRACT

Ptolemy is a flexible tool that has been developed for simulation, prototyping, and software synthesis for large heterogeneous systems. The objectives of Ptolemy encompass virtually all aspects of designing signal processing and communication systems, ranging from algorithms and communication strategies, through simulation, parallel computing, and generation of real-time prototypes. This project report describes the multiprocessor code synthesis aspect of Ptolemy, and in particular, code synthesis for the Sproc digital signal processor (DSP) made by Star Semiconductor.
