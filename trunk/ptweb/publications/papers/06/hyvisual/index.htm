HyVisual: A Hybrid System Modeling Framework Based on Ptolemy II

Edward A. Lee and Haiyang Zheng

to appear in IFAC Conference on Analysis and Design of Hybrid Systems (ADHS'06)
to be held in Alghero, Sardinia, June 7-9, 2006.

 

ABSTRACT

HyVisual is a hybrid systems modeling framework providing a block diagram visual syntax for specifying continuous dynamics and a bubble-and-arc syntax for specifying modal behavior. It is based on Ptolemy II, is written in Java, and is distributed open-source at http://ptolemy.eecs.berkeley.edu/hyvisual/.
