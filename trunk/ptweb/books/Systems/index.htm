System Design, Modeling, and Simulation

Claudius Ptolemaeus, Editor System Design, Modeling, and Simulation, Ptolemy.org, Download Draft Version 0.04, 2011.

This book describes the principles and practice of system design, modeling, and simulation, using Ptolemy II to illustrate the mechanisms. The emphasis is on concurrent models of computation (MoCs) with applications to software systems, embedded systems, and cyber-physical systems modeling. The MoCs covered include process networks, synchronous/reactive, concurrent state machines, dataflow, rendezvous (e.g. CSP, CCS), time-triggered models, discrete-events, and continuous-time models. Compositions of MoCs, such as hybrid systems and Statecharts, are also discussed.
