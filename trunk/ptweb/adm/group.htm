Adding Pages to the Group Website

There are separate instructions for adding publications, and for adding to the public website, these instructions are for adding to the group web page at http://ptolemy.eecs.berkeley.edu/~ptII
  1. The Ptolemy Group website is under CVS as ptIIweb. You can either check out a copy and make your changes, or just modify the files in ~ptII/public_html. It is easier to modify the files in ~ptII/public_html, so that is what is documented below.
  2. Go to the directory where you want your new page, and copy an adjacent page. The key part is to get the header right so that the it looks similar to: 
    <html>
<head>
<META HTTP-EQUIV="Content-Type" CONTENT="text/html; charset=iso-8859-1">
<link href="../lib/default.css" rel="stylesheet" type="text/css">
<title>Adding Pages to the Group Website</title>
  3. Be sure to consult the Style guide.
  4. Add a link to your file to the toc.htm file
  5. Verify that your changes are correct.
  6. Add your new file to CVS 
    cvs add yournewfile.htm
  7. Commit your changes 
    cvs commit -m "Added yournewfile.htm" yournewfile.htm toc.htm
