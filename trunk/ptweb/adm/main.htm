How to update web pages

There are separate instructions for adding publications, and for instructions for adding Group Web pages these instructions are for the Public website in general.
  1. The Ptolemy Website is under CVS. To check out a copy of the Ptolemy website 
    cvs -d /users/cvs/Repository co ptweb
  2. Modify your copy of the website to suit your needs. Be sure to consult the Style guide.
  3. To update the publically visible website, become the ptII user on messier. To become the ptII user, you will need to have a kerberos principle, and have your name added to ~ptII/.klogin. If your name is not in ~ptII/.klogin, then send mail to root@mho.eecs.berkeley.edu.
    To become the ptII user, get a Kerberos principle, then use rlogin: 
    kinit
rlogin -8xl ptII messier
  4. As ptII, cd to the location of the website: 
    cd /vol/ptolemy/pt0/ptweb
  5. As ptII, run cvs update
  6. Verify that your changes are correct.
