Adding Publications

With the introduction of the new website, the instructions for adding new publications have changed.

The papers directory is available on the web as http://ptolemy.eecs.berkeley.edu/publications

The website is actually located on messier in /vol/ptolemy/pt0/ptweb. The ptII user has write privileges to that directory.

If you want to add a paper to the website, please follow the instructions below

  1. Be sure that you have the proper acknowledgement of support in your paper. As of 10/97, the text was:
    This research is part of the Ptolemy project, which is supported by the Defense Advanced Research Projects Agency (DARPA), the State of California MICRO program, and the following companies: The Alta Group of Cadence Design Systems, Hewlett Packard, Hitachi, Hughes Space and Communications, NEC, Philips, and Rockwell.
  2. Ideally your paper should include the ERL memo number in the paper. At the minimum, the abstract should include the ERL memo number. ERL memo numbers can be had by emailing Tito.
    ERL Research Publications website lists current publications
    FIXME: we need more info here.
  3. Create a PDF version of your paper. If you only have PostScript, you can convert it under Unix with: 
    distill your_paper_name.ps
  4. The website is now under cvs control. However, because of size constraints, the directories that contain the papers are not under CVS control To add a publication, you should check out the website with: 
    cvs checkout ptweb
  5. The publications are organized by year in the ptweb/publications/twodigityear directory.
    For example, the directories that contain the papers for 1999 would all be in ptweb/publications/papers/99
  6. In the yearly publications directory, create a directory for the html file that includes your abstract and the pdf file. For example, I might create ptweb/publications/papers/99/loopedSchedules

    Make sure that your directory name makes sense and is informative. For example, "masters" is not a good choice, while the name "loopedSchedules" is a much better one. Also make sure that your directory name is different from that of any of the other files in the yearly publications directory

    Note that the directory that contains the abstract and pdf file are not under CVS.

  7. Copy your pdf file to the directory. Again, the names of the files should be informative
  8. Create an index.htm file in the directory you just created, using a recent index.htm file as a sample. Don't deviate from the standard.
  9. Be sure to link to the style sheet
  10. Have a link to the PDF at the top, before the abstract
  11. Include an abstract
    To get the abstract where only have PostScript and PDF, use acroread to grab the text from the pdf file. 
    acroread your_paper_name.pdf
    Use 'select text' under the tools menu to highlight the text for the abstract and then copy it to your index.html file. You will need to polish the formatting a little after making the copy (eliminate inappropriately hyphenated words, fill in dropped letters, e.g., occurrences of "fl" or "ff").
  12. Include the ERL Memo number
    13. Note that the index.htm file for the paper is not under CVS
  13. The yearly publications directory contains a index.htm file, which is where you should add a reference to your paper. For example, the papers for 1999 would all be listed ptweb/publications/papers/99/index.htm
    The papers are listed chronologically, add your paper to the top. Use the previous paper as an example.
    Please don't deviate from the standard, this is not place to exercise artistic license :-)
    This file is under CVS version control, when you are done, check the file in with cvs commit -m "added foo paper" index.htm
  14. Check that your links are ok by point a browser to your copy of the website
  15. The next step is to update the website. Become the ptII user on messier: 
    rlogin -8x messier ptII
  16. Go to /vol/ptolemy/pt0/ptweb/publications/papers/year and copy the directory that contains your .pdf file and the index.htm file you created. Note that these file are not under CVS. 
    cd /vol/ptolemy/pt0/ptweb/publications/papers/99
cp -r ~/src/ptweb/publications/papers/99/loopedSchedules .
  17. Get the latest version of the index.htm file 
    cvs update
  18. Check your changes by going to: http://ptolemy.eecs.berkeley.edu/publications
    Note that you might have to click reload in your browser to see the changes.
