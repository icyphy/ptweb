Installing Ptolemy 0.7.2 Under Linux

Below are notes about installing under Red Hat 8 in July, 2003

It might be worth trying the rpms on ftp://ftp.tu-ilmenau.de/pub/unix/ptolemy/ptolemy0.7.1.linux

  1. See Download Ptolemy 0.7.2 for instructions about how to access Ptolemy Classic 0.7.2
    You will need 
    pt0.7.2devel.other.src.tar.gz
pt0.7.2devel.src.tar.gz
pt0.7.2devel.gnu.tar.gz
    We recommend putting them in a ~/downloads directory.
  2. Untar the files: 
    cd /root
tar -zxf downloads/pt0.7.2devel.gnu.tar.gz
tar -zxf downloads/pt0.7.2devel.src.tar.gz
tar -zxf downloads/pt0.7.2devel.other.src.tar.gz
  3. Create $PTOLEMY/.bashrc and add the following 
    PTOLEMY=/root/ptolemy
export PTOLEMY

PTARCH=linux
export PTARCH

PATH=$PTOLEMY/bin:$PTOLEMY/bin.$PTARCH:$PTOLEMY/vendors/bin:$PATH

# To use the X11 pxgraph, follow the instructions
# in $PTOLEMY/src/pxgraph/README.txt and uncomment the next line.
PT_USE_X11_PXGRAPH=yes
export PT_USE_X11_PXGRAPH

  4. source /root/ptolemy/.bashrc
  5. Start the compile: 
    cd $PTOLEMY
make bootstrap >& boot.out &
  6. If you get messages like: 
    mkdir /root/ptolemy/gnu/common/share/locale/de/LC_MESSAGES
 /usr/bin/install -c -m 644 de.mo /root/ptolemy/gnu/common/share/locale/de/LC_MESSAGES/make.mo
/usr/bin/install: cannot stat `de.mo': No such file or directory
    Do 
    cd $PTOLEMY/obj.linux/gnu/make/i18n
ln -s  ../../../../src/gnu/src/make/i18n/* .
    and restart: 
    cd $PTOLEMY
make bootstrap >& boot2.out &

    /root/ptolemy/src/tcltk/tcl8.0.5pt/unix/../generic/tclPosixStr.c: In function `
Tcl_ErrnoId':

he first entry for that value
    The fix is to edit ~/ptolemy/src/tcltk/tcl8.0.5pt/generic/tclPosixStr.c and comment out the EOPNOTSUPP in two locations 
                   /*#ifdef EOPNOTSUPP
        case EOPNOTSUPP: return "EOPNOTSUPP";
#endif
                */
    and 
                  /*#ifdef EOPNOTSUPP
        case EOPNOTSUPP: return "operation not supported on socket";
        #endif*/
    I then restarted with 
    make install_tcltk
  8. Proceed with installing octtools: 
    make install_octtools >& oct.out &
  9. Proceed with the build 
    make install >& install.out &

  14. pxgraph fails to compile 
    ../../../src/pxgraph/pxgraph/xgraph.h:77:21: macro "strchr" requires 2 arguments, but only 1 given
    The fix is to edit ptolemy/src/pxgraph/pxgraph/xgraph.h and comment out the declaration of strchr
    Then run make install
  15. Run a sample demo by doing 
    cd $PTOLEMY
ptiny src/domains/sdf/demo/butterfly
    After the Ptolemy Welcome Window comes up, move the mouse over the model and type a capital R to run it.
  16. When running a model that uses the Java version of pxgraph, the output is screwy. For example, the butterfly model results in in the 10^38 range. The problem here is with the binary data format of the Java version of pxgraph. The solution is to use the X11 version of pxgraph by doing: 
    PT_USE_X11_PXGRAPH=yes
export PT_USE_X11_PXGRAPH
    (The sample .bashrc above has been adjusted accordingly)
