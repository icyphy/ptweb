Viptos - Visual interface between Ptolemy and TinyOS

Screenshots

This page shows screenshots of SenseToLeds. SenseToLeds is an example Viptos model that contains a model of a light source, as well as a node running the TinyOS 1.x SenseToLeds program, which displays the sensed light level in binary on the LEDs of the node.
