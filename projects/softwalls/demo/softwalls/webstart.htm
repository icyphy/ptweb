Soft Walls Web Edition Download

This download of the Soft Walls demonstration uses a web launching tool called Web Start that makes installation and updates particularly simple.

Quick Start

Installation Details

Web Start is a product from Sun that is used to download this version of the Soft Walls demonstration.
  1. This web page attempts to detect whether Web Start is already installed. If the Quick Start list above contains
    Install Web Start from Sun (720KB - 8.6Mb)
    then download and install Web Start by following the Install Web Start from Sun (720Mb - 8.6Mb) link.

    If you already have the Java Runtime Environment version 1.4 (JRE 1.4) or higher installed, you only need the Java Web Start Update, which is 720Mb.

    If you do not have the Java Runtime Environment installed, or you are not sure, then you would need to download the Full Java Web Start package (5.7Mb), which includes a JRE.
    If the above step is not present, then Web Start is already installed and you can proceed with clicking on the

    Soft Walls Demonstration (~10.1Mb)
    link and continue with step 4 below.
  2. After installing Web Start, restart your browser and return to this page.
  3. Hopefully, the Web Start detection will work and the Install Web Start from Sun (720KB - 8.6Mb) step will not be present.
    Even if the Install Web Start step is present, try downloading and/or opening the Soft Walls Demonstration (~10.1Mb), it could be that the Web Start detection has failed even though Web Start is properly installed.
    For example, under Opera 6.01 under Windows 2000, click on the Soft Walls Demonstration (~10.1Mb) link and select open. If Java Web Start has been installed, then it should start up automatically.
  4. The download is roughly 10.1Mb and includes Java 3D for Windows.
  5. After the download completes, you will be prompted with a window that states that the certificate from University of California Berkeley is valid. You should hit the Start button to proceed with start up.
    The download needs full access to your machines so that it can run the Java 3d native libraries (dlls).
  6. Hit the "Go" button.
    When the demonstration is running, use the left and right arrow keystrokes to steer the plane. Note that you cannot steer the plane into the red no-fly zone.

    When the demonstration starts up, a small Java window will appear outside your browser.
    This window must have the focus (be on the top and have the title bar highlighted) so that it can accept your left and right arrow key strokes that will steer the plane.
    For example, if you press the go button and move the main window, then the small Java window might not have the focus and you won't be able to steer the plane.
