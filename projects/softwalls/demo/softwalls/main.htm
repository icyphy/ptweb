Soft Walls Demonstration

A simple demonstration of a Soft Wall is available in the following formats

  • Applet Demo - requires Java and Java 3d (4.5Mb)
  • WebStart Demo - requires Java, includes Java3d (10.1Mb)
  • Model Applet - requires Java and Java 3d, shows the top level of the model. (6.6Mb)
    • All three run the same model

    When the demonstration is running, use the left and right arrow keystrokes to steer the plane. Note that you cannot steer the plane into the red no-fly zone.

    The demonstration requires that Java 3D be installed from Sun.

    The demonstration itself requires a download of roughly 4.5Mb.

    When the demonstration starts up, a small Java window will appear outside your browser.
    This window must have the focus (be on the top and have the title bar highlighted) so that it can accept your left and right arrow key strokes that will steer the plane.
    For example, if you scroll down the main applet window, then the small Java window will be obscured and you won't be able to steer the plane.

    If you do not steer the plane, then as it approaches the red no-fly zone, it will steer away from it.

    If you try to steer the plane into the red no-fly zone, then as it approaches the no-fly zone, the blending controller will provide more and more input, preventing the plane entering the no-fly zone.

    Details about the implementation

    The simulation uses Ptolemy II to simulate the dynamics of the airplane using Continuous Time semantics.

    The block diagram for the model was constructed using the Ptolemy II schematic editor called vergil.

    The plane itself is rendered using Java 3D.

    Limitations

    • When the demonstration starts up, there will be a short delay while the model is reading in the data files.
    • Note that when running the model, the small Java window in that pops up outside this window must have the focus so that it can get the left arrow and right arrow keystrokes.
      For example, if you scroll down the main applet window, then the small Java Applet Window will be obscured and you won't be able to steer the plane.
    • The dynamics of the plane are not simulated - real commercial jetliners cannot turn on a dime. The point here is that we are blending the control - as the plane gets closer to the no-fly zone, it ignores the pilot's commands more and more until it eventually turns away.
      Control can be regained by steering away from the no-fly zone.
    • The wingtip of the plane might end up in the no-fly zone. The point here is that the center of the plane stays out of the no-fly zone.
    • You might experience out of memory errors. There are four data sets of roughly 1,000,000 doubles each that consume quite a bit of memory. If the model appears to hang, try restarting your browser.
