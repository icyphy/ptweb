Soft Walls

A simple demonstration of a Soft Wall no-fly zone. Use the arrow keys to steer the plane.
Note that when running the model, the small Java Applet Window in that pops up outside this window must have the focus so that it can get the left arrow and right arrow keystrokes.
For example, if you scroll down the main applet window, then the small Java Applet Window will be obscured and you won't be able to steer the plane.

See the description for details.
