Standalone Marks

This directory contains the minimal files needed to plot using Ptplot3.1.

Ptplot3.1 is the last release of Ptplot that does not require the Java 1.3 Plug-in.

  • The Ptplot3.1 page is at http://ptolemy.eecs.berkeley.edu/java/ptplot3.1/ptolemy/plot/doc/index.htm
  • The Ptplot home page is at http://ptolemy.eecs.berkeley.edu/java/ptplot/
    • This directory contains the following files.
    StandaloneMarks.htm (this file)
    This file is based on http://ptolemy.eecs.berkeley.edu/java/ptplot3.1/ptolemy/plot/demo/Marks.htm
    To view the applet code for this file, use view source in your browser.
    standalonePlotMLSample.txt
    Based on http://ptolemy.eecs.berkeley.edu/java/ptplot3.1/ptolemy/plot/demo/plotmlSample.txt

    However, standalonePlotMLSample.txt refers to the dtd as 

    <!DOCTYPE plot SYSTEM "plotml.dtd"?>
    plotml.dtd
    Exact copy of http://ptolemy.eecs.berkeley.edu/java/ptplot3.1/ptolemy/plot/plotml/plotml.dtd
    This file defines syntax of the PlotML language.
    plotmlapplet.jar
    Exact copy of http://ptolemy.eecs.berkeley.edu/java/ptplot3.1/ptolemy/plot/plotmlapplet.jar
    The above files can be found in a zip file at http://ptolemy.eecs.berkeley.edu/java/ptplot/standalone/ptplot3.1standalone.zip
