Instructions for Presenters and Poster Makers

Instructions for Presenters

Each presentation will be 20 minutes long, including questions and set up time.

To decrease set up time, it would help if all of the presentations were on our presentation laptops.

We would like to make all the presentations available in a printed hand out and on the Ptolemy website as 2up PDF files. Let us know if this would be a problem. If possible, please email your Powerpoint presentation to ptconf01 at ptolemy eecs berkeley edu by 6am Monday, March 12.

Ideally, current Ptolemy group presenters will use the standard Powerpoint template.

Instructions for Poster Makers

We would like to make all the posters available in a printed handout and on the Ptolemy website as 2up PDF files. Let us know if this would be a problem.
